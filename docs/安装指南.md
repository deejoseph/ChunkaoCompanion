## 快速安装（推荐）

### 方法一：自动安装脚本

1. 双击运行 `install.bat`
2. 等待依赖安装完成（约 3-5 分钟）
3. 双击运行 `start.bat` 启动服务
4. 浏览器访问 `http://localhost:3000`

### 方法二：手动安装（如果自动安装失败）

```bash

cd D:\PixelSmile\ChunkaoCompanion

# 6. 启动服务
# 终端1: cd backend && node app.js

口语练习模块
口语模块支持两种模式：

快速模式（默认）
使用浏览器 Web Speech API

无需额外安装

支持实时语音识别

松开空格键立即识别

精准模式（Whisper）
使用本地 Whisper 模型，识别更准确，适合正式练习和评分。

1. 安装 Python 3.8+
下载地址：https://www.python.org/downloads/

安装时务必勾选：Add Python to PATH

验证安装：

bash
python --version
2. 安装 ffmpeg（音频处理）
下载地址：https://www.gyan.dev/ffmpeg/builds/

下载 ffmpeg-release-full.7z 或 ffmpeg-release-full.zip

解压到 C:\ffmpeg

将 C:\ffmpeg\bin 添加到系统 PATH

验证安装：

bash
ffmpeg -version
3. 安装 faster-whisper
bash
pip install faster-whisper
4. 验证安装
bash
python -c "from faster_whisper import WhisperModel; print('Whisper 安装成功')"
5. 使用说明
首次使用精准模式会下载模型（约 1-2 分钟，模型大小约 4.9GB）

推荐使用快速模式，响应更快

精准模式适合正式评分和复杂发音识别

常见问题
Q: 快速模式识别不准确？
A: 快速模式使用浏览器内置识别，受网络和环境音影响。可以切换到精准模式获得更好效果。

Q: Whisper 模型下载慢？
A: 首次使用会自动下载，可以设置代理或耐心等待。模型缓存后后续使用无需重新下载。

Q: ffmpeg 找不到？
A: 确保将 C:\ffmpeg\bin 添加到系统 PATH，然后重启命令提示符。

常见问题
1. 端口被占用
bash
# 查看占用端口的进程
netstat -ano | findstr :3000
netstat -ano | findstr :3001

# 终止进程（替换 PID）
taskkill /PID <PID> /F
2. Ollama 服务未启动
检查系统托盘是否有 Ollama 图标

如果没有，从开始菜单启动 Ollama

或运行 ollama serve 启动服务

3. Whisper 识别失败
确保 Python 环境和 faster-whisper 已正确安装：

bash
python -c "from faster_whisper import WhisperModel; print('OK')"
4. 前端启动失败
删除 node_modules 重新安装：

bash
cd frontend
rmdir /s /q node_modules
npm install
5. 模型下载慢
Ollama 模型下载可能较慢，可以：

使用代理

或从 Hugging Face 手动下载后放到 ~/.ollama/models/ 目录
