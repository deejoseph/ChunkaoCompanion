# 春考助学系统 - 本地安装与运行指南

本指南适用于 **Windows / macOS / Linux** 系统。  
你将一步一步地搭建开发环境、下载代码、安装依赖、初始化数据库，并最终在浏览器中访问系统。

> 📌 目标：**不依赖一键脚本**，手动执行每条命令，理解部署流程。

## 1. 准备工作：安装基础工具

### 1.1 安装 Git（版本控制）
- **作用**：从 GitHub 克隆项目代码。
- **安装方法**：
  - Windows：下载 [Git for Windows](https://git-scm.com/download/win)，安装时保持默认选项。
  - macOS：`brew install git` 或下载官方安装包。
  - Linux：`sudo apt install git`（Debian/Ubuntu）。

验证安装：
```bash
git --version
```

### 1.2 安装 Node.js 和 npm
- **作用**：运行后端服务（Node.js）并管理前端/后端依赖（npm）。
- **要求**：Node.js 18+ 和 npm 9+。
- **安装方法**：
  - 官网下载：https://nodejs.org/ （选择 LTS 版本）
  - 或使用版本管理工具（如 nvm、fnm）。

验证：
```bash
node --version
npm --version
```

### 1.3 安装 Python 3
- **作用**：运行数据迁移、测试以及未来数据分析脚本（部分后端脚本使用 Python）。
- **要求**：Python 3.9+。
- **安装方法**：
  - Windows：从 [python.org](https://www.python.org/downloads/) 下载，**务必勾选 “Add Python to PATH”**。
  - macOS/Linux：通常已预装，若版本过低可用 `brew install python` 或 `apt install python3`。

验证：
```bash
python --version   # 或 python3 --version
```

## 2. 获取项目源代码

打开终端（命令提示符 / PowerShell / Terminal），进入你希望存放项目的目录（例如 `~/projects`）。

```bash
git clone https://github.com/deejoseph/ChunkaoCompanion.git
cd chunkao-assistant
```

> 🔁 实际仓库地址请替换为真实地址。若你使用的是教师分发的压缩包，可跳过 `git clone`，直接解压并进入目录。

查看项目结构（了解各目录作用）：
```
chunkao-assistant/
├── backend/          # Node.js 后端代码
├── frontend/         # React 前端代码
├── data/             # SQLite 数据库文件及 JSON 备份
├── scripts/          # 辅助脚本（Python）
└── README.md
```

## 3. 安装后端依赖

后端是一个 Express 应用，依赖项写在 `backend/package.json` 中。

```bash
cd backend
npm install
```

**这一步做了什么？**  
- npm 读取 `package.json`，下载所有需要的 Node.js 库（如 express、sqlite3、multer、pdf-parse 等）到 `node_modules` 文件夹。
- 安装完成后，会在 `backend` 目录下生成 `package-lock.json` 锁定版本。

## 4. 安装前端依赖

打开新的终端窗口（或先切回项目根目录）：

```bash
cd frontend
npm install
```

**作用**：安装 React、Vite、UI 库、HTTP 客户端等前端依赖。

## 5. 初始化数据库

本系统使用 **SQLite** 作为主数据库，无需单独安装数据库服务器。数据库文件位于 `data/knowledge/chunkao.db`。

### 5.1 检查数据库是否存在
如果项目是从 Git 克隆的，`data/knowledge/chunkao.db` 可能**不在版本控制中**（被 .gitignore 忽略），因此需要你手动初始化。

### 5.2 运行数据库迁移脚本

项目提供了 SQL 初始化脚本（如 `backend/scripts/init-db.sql`）或 Node.js 迁移脚本。

推荐使用 Node.js 脚本（跨平台）：

```bash
cd ../backend   # 确保在 backend 目录下
node scripts/initDb.js
```

如果看到 `Database initialized successfully` 表示成功。

**如果没有提供 Node 脚本**，可以手动执行 SQL：

```bash
# 进入 data/knowledge 目录
cd ../data/knowledge
sqlite3 chunkao.db < ../../backend/schema.sql
```

> 📌 SQLite 命令行工具：Windows 需单独下载，macOS/Linux 通常预装。若没有，可跳过手动 SQL，直接用 Node 脚本。

### 5.3 导入初始数据（可选）

部分项目提供了种子数据（例如预设的 `topics`、`knowledge_points`）：

```bash
cd ../../backend
node scripts/seed.js
```

## 6. 配置环境变量

后端需要一些环境变量（如端口、JWT 密钥、AI 接口密钥）。项目根目录或 `backend` 目录下应该有一个 `.env.example` 文件。

```bash
cd backend
cp .env.example .env
```

编辑 `.env` 文件（可用记事本、vim、vscode），至少设置以下内容：

```
PORT=3001
JWT_SECRET=your_strong_secret_key_here
AI_API_KEY=sk-xxxxx   # 如果有 AI 功能（如 DeepSeek），填入真实 key
```

> 🔐 实际项目中，AI 密钥需要你自己申请（例如 DeepSeek、OpenAI）。如果不使用 AI 功能，可以留空或填占位符。

## 7. 运行后端服务

在 `backend` 目录下执行：

```bash
npm run dev
```

你会看到类似输出：
```
Server running on http://localhost:3001
Database connected: data/knowledge/chunkao.db
```

**保持这个终端窗口运行**（不要关闭）。

## 8. 运行前端开发服务器

打开**另一个终端窗口**，进入 `frontend` 目录：

```bash
cd frontend
npm run dev
```

输出：
```
VITE v5.x  ready in 300ms
➜  Local:   http://localhost:5173/
```

## 9. 访问系统

在浏览器中打开 `http://localhost:5173`。  
你应该能看到春考助学系统的界面（登录页或采集工作台）。

### 9.1 首次登录
项目可能没有默认账号。你可以：
- 使用系统自带的注册功能（如果有）
- 或通过后端脚本创建一个测试账号：

```bash
cd ../backend
node scripts/createUser.js --username admin --password 123456
```

## 10. 验证核心功能

1. **题库采集**：点击“题库采集” → 上传一个 PDF 试卷 → 等待解析 → 保存到 SQLite。
2. **知识点采集**：点击“知识点采集” → 选择学科/资料 → AI 生成 JSON 草稿 → 校对。
3. **答案管理**：在题目列表中打开 AI 答案侧栏，修改后保存。

## 常见问题排查

| 现象 | 可能原因 | 解决方法 |
|------|----------|----------|
| `npm install` 失败 | 网络问题或 node 版本过低 | 切换镜像源 `npm config set registry https://registry.npmmirror.com`；升级 Node.js |
| 后端启动报错 `SQLITE_CANTOPEN` | 数据库目录不存在或权限不足 | 手动创建 `data/knowledge` 目录：`mkdir -p data/knowledge` |
| 前端请求后端接口 404 | 后端未运行或端口不一致 | 检查后端终端输出；检查 `.env` 中 `VITE_API_BASE_URL` 是否指向 `http://localhost:3001` |
| AI 功能返回空 | 未配置 `AI_API_KEY` 或余额不足 | 编辑 `backend/.env`，重启后端 |
