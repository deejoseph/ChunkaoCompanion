## 快速安装（推荐）

### 方法一：自动安装脚本

1. 双击运行 `install.bat`
2. 等待依赖安装完成（约 3-5 分钟）
3. 双击运行 `start.bat` 启动服务
4. 浏览器访问 `http://localhost:3000`

### 方法二：手动安装（如果自动安装失败）

```bash
# 1. 打开命令提示符，进入项目目录
cd C:\ChunkaoCompanion

# 2. 安装后端依赖
cd backend
npm install

# 3. 安装前端依赖
cd ..\frontend
npm install

# 4. 安装 Markdown 渲染插件（必需）
npm install remark-gfm rehype-katex remark-math --save

# 5. 创建必要目录
cd ..
mkdir data\docs 2>nul
mkdir backend\uploads 2>nul
mkdir backup 2>nul

# 6. 启动服务
# 终端1: cd backend && node app.js
# 终端2: cd frontend && npm run dev
AI 模型安装
安装 Ollama
下载：https://ollama.com/download

安装后，Ollama 会自动在后台运行

打开命令提示符，下载所需模型：

bash
# 必需模型
ollama pull qwen2.5:7b      # 通用快速模型
ollama pull qwen2.5:14b     # 专业模型
ollama pull qwen2-math:7b   # 数学专用
ollama pull glm4:9b         # 语文古文优化
ollama pull gemma3:4b       # 英语专用

# 可选模型
ollama pull qwen2-math:1.5b    # 数学轻量
ollama pull qwen2.5-coder:7b   # 公式美观
验证 Ollama 运行
bash
curl http://localhost:11434
返回 Ollama is running 表示成功。

口语模块依赖（Whisper）
如果需要使用 Whisper 精准识别：

安装 Python 依赖
bash
# 安装 Python 3.8+ 后，执行：

安装 ffmpeg
下载：https://ffmpeg.org/download.html

解压到 C:\ffmpeg

将 C:\ffmpeg\ffmpeg\bin 添加到系统 PATH

常见问题
1. remark-gfm 模块找不到
bash
cd frontend

2. 端口被占用

# 查看占用端口的进程

# 终止进程
taskkill /PID <PID> /F
3. Ollama 连接失败
检查系统托盘是否有 Ollama 图标

如果没有，从开始菜单启动 Ollama

4. 前端启动后空白
按 F12 打开开发者工具，查看 Console 错误

确认后端服务是否正常运行（访问 http://localhost:3001/api/health）
