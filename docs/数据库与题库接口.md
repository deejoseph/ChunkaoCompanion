# 数据库与题库接口说明

本文档记录当前项目中知识库、题库、知识点关联、题目资产相关的数据库结构与后端接口。

> 重点变化提示：旧记录中曾写到“Node.js 暂未引入 SQLite 依赖”“数学 qwen 真题拆分后 28 题”“解答题小问自动展开成独立题目”。这些已经改变。当前后端已经通过 `sqlite3` 和 `sqlite` 直接读写 SQLite；数学上海春考 qwen 真题按 21 道大题入库；解答题小题保留在父题内容、答案和解析中，不再拆成独立题目行。

## 数据库位置

```text
data/knowledge/chunkao.db
```

当前数据库由 Python 脚本和 Node 后端共同维护：

- Python 脚本负责初始化、重建知识图谱、批量查询、历史导入。
- Node 后端负责题库保存、JSON 上传导入、答案更新、题目资产上传、部分知识点保存。

## 当前题库导入口径

### 普通题库 JSON

支持结构：

```json
{
  "paperId": "math_2026_sample",
  "title": "示例题库",
  "subject": "math",
  "version": "2026",
  "questions": [
    {
      "id": "q1",
      "type": "qa",
      "content": "题干",
      "sourceAnswer": "答案",
      "analysis": "解析",
      "score": 10,
      "difficulty": "",
      "images": [],
      "knowledgePoints": []
    }
  ]
}
```

### qwen 真题 JSON

支持结构：

```json
{
  "exam_info": {
    "title": "上海市春季高考数学试卷",
    "year": 2023,
    "total_score": 150
  },
  "sections": [
    {
      "type": "fill_in_the_blank",
      "questions": []
    },
    {
      "type": "multiple_choice",
      "questions": []
    },
    {
      "type": "essay",
      "questions": [
        {
          "id": 17,
          "total_score": 14,
          "title": "解答题标题",
          "content": "父题题干",
          "sub_questions": []
        }
      ]
    }
  ]
}
```

数学上海春考 qwen 真题当前按固定大题结构导入：

| 类别 | 题数 | 分值 |
| --- | ---: | ---: |
| 填空题 | 12 | 54 |
| 选择题 | 4 | 20 |
| 解答题 | 5 | 76 |
| 合计 | 21 | 150 |

具体规则：

- 填空第 1-6 题每题 4 分，第 7-12 题每题 5 分。
- 选择题每题 5 分。
- 解答题第 17-21 题分别为 14、14、14、16、18 分。
- 解答题 `sub_questions` 不单独写入 `questions` 表，而是合并到父题的 `content`、`source_answer`、`analysis`。
- 2021 年 qwen 源 JSON 第 20 题曾写成 14 分，但同文件说明与上海春考固定结构应为 16 分，导入器已按固定结构归一化。

### 知识库接口：`/api/knowledge`

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| `POST` | `/api/knowledge/init` | 初始化数据库，可触发扫描 `data/docs` |
| `GET` | `/api/knowledge/summary` | 查询数据库统计 |
| `GET` | `/api/knowledge/topics?subject=math&version=2026` | 查询专题及其知识点 |
| `GET` | `/api/knowledge/points?subject=chinese` | 查询知识点 |
| `GET` | `/api/knowledge/banks?subject=math&version=2026&limit=20` | 查询题库列表和关联进度 |
| `GET` | `/api/knowledge/questions?subject=math&bankId=xxx&limit=20` | 查询题目 |
| `POST` | `/api/knowledge/import-question-banks` | 导入历史 `data/question_banks/*_question_bank.json` |
| `POST` | `/api/knowledge/link-question-knowledge` | 规则生成题目与知识点关联 |
| `POST` | `/api/knowledge/import-json` | 上传单个知识点 JSON，写入知识库与知识图谱 |
| `POST` | `/api/knowledge/save` | 保存前端校对后的知识点 JSON |
| `GET` | `/api/knowledge/source-answers?subject=chinese&title=专题名` | 获取题库 ID 与题目 `source_answer` |

#### `POST /api/knowledge/import-json`

表单字段：

| 字段 | 说明 |
| --- | --- |
| `file` | 上传的知识点 JSON |
| `subject` | 学科，默认 `chinese` |
| `version` | 版本，默认 `2026` |
| `clearExisting` | 是否清空后导入，布尔或字符串 `true` |

写入表：

- `topics`
- `knowledge_points`
- `topic_knowledge_points`
- `knowledge_nodes`
- `knowledge_edges`
- `exam_insights`
- `source_files`

说明：

- 当前知识点资料来源以 `data/docs/{subject}/2026/*.json` 为主。
- 上传接口内部复用 `backend/scripts/rebuild_knowledge_from_json.py --input-files`。
- 如果 `clearExisting=true`，脚本会清空知识库和题库相关表后重建，使用前要确认当前数据库可被重置。

### 题库接口：`/api/banks`

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| `POST` | `/api/banks/import-json` | 上传题库 JSON 或 qwen 真题 JSON，直接导入数据库并生成 JSON 备份 |
| `POST` | `/api/banks/save` | 保存题库到 SQLite，并生成 JSON 备份 |
| `POST` | `/api/banks/upload-asset` | 上传题目图片、截图、公式图等资产 |
| `GET` | `/api/banks/list` | 查询题库列表 |
| `GET` | `/api/banks/search?subject=math&title=xxx` | 按学科和标题查找题库，优先查 SQLite，JSON 仅兜底 |
| `GET` | `/api/banks/:id` | 获取单个题库，优先查 SQLite，JSON 仅兜底 |
| `DELETE` | `/api/banks/:id` | 删除单个题库，同时清理 SQLite、JSON 备份和资产目录 |
| `DELETE` | `/api/banks/subject/:subject` | 删除某学科 JSON 备份。注意：该接口仍是旧逻辑，未同步删除 SQLite |
| `POST` | `/api/banks/update-answer` | 按 `bankId + questionNumber` 更新 `questions.source_answer` |

> 重点变化提示：`DELETE /api/banks/:id` 已改为同步删除 `question_banks`、`questions`、`question_assets`、`question_knowledge_points`，并清理 JSON 备份和资产目录。旧的 `DELETE /api/banks/subject/:subject` 仍只清理 JSON 文件，不应作为数据库清库入口。

#### `POST /api/banks/import-json`

表单字段：

| 字段 | 说明 |
| --- | --- |
| `file` | 上传的题库 JSON |

写入行为：

- 解析普通题库 JSON 或 qwen 真题 JSON。
- 写入 `question_banks`。
- 删除同一 `bank_id` 旧题目、旧资产关联、旧知识点关联。
- 写入 `questions`。
- 如果题目带 `image`、`imagePath`、`images`，写入 `question_assets`。
- 如果题目带 `knowledgePoints` 或 `knowledge_points`，并且名称能匹配现有 `knowledge_points.name`，写入 `question_knowledge_points`。
- 在 `data/question_banks/{paperId}_question_bank.json` 生成 JSON 备份。

响应示例：

```json
{
  "success": true,
  "bankId": "math_2022_上海市春季高考数学试卷",
  "title": "上海市春季高考数学试卷",
  "totalQuestions": 21,
  "jsonPath": "data/question_banks/math_2022_上海市春季高考数学试卷_question_bank.json"
}
```

#### `POST /api/banks/save`

JSON 字段：

| 字段 | 说明 |
| --- | --- |
| `paperId` | 题库 ID，必填 |
| `title` | 题库标题，必填 |
| `sourceTitle` | 来源标题 |
| `subject` | 学科 |
| `version` | 版本 |
| `sourcePath` | 来源路径 |
| `sourceFormat` | 来源格式 |
| `paperType` | 试卷类型 |
| `knowledgePoints` | 题库级知识点 |

说明：

- 内部复用 `backend/services/saveParsedBank.js`。
- 保存时会以 `paperId` 为准覆盖同一题库。
- 旧题目、旧资产关联、旧知识点关联会先删除，再重新插入。

#### `POST /api/banks/upload-asset`

表单字段：

| 字段 | 说明 |
| --- | --- |
| `file` | 图片或截图文件 |
| `bankId` | 题库 ID |
| `questionId` | 题目编号或题目短 ID |

| `bboxJson` | 截图区域 JSON |

写入位置：

```text
data/question_assets/{bankId}/{questionId}/
```

```text
question_assets.question_id = {bankId}_{questionId}
```

#### `POST /api/banks/update-answer`

请求体：

```json
{
  "bankId": "math_2022_上海市春季高考数学试卷",
  "questionNumber": 17,
  "sourceAnswer": "新的参考答案"
}
```

说明：

- 主匹配条件是 `questions.bank_id + questions.number`。
- 如果精确匹配失败，会用 `bank_id LIKE %bankId%` 做兼容兜底。
- 只更新 `questions.source_answer` 和 `updated_at`。

| `POST` | `/api/docs/parse-corrected` | 解析校正后的文本，可选写入数据库 |
| `GET` | `/api/docs/answer-sheet/:subject/:topicId` | 获取答题卡 HTML |

#### `POST /api/docs/parse-corrected`

核心字段：

| 字段 | 说明 |
| --- | --- |
| `correctedText` | 校正后的文本 |
| `answerMarker` | 答案标记 |

当 `saveToDb=true` 时：

- 写入 `question_banks` 和 `questions`。

- 使用同一个 `saveParsedBank` 服务，行为与 `/api/banks/save` 基本一致。

## 脚本

### 初始化知识库

```bash
python backend/scripts/init_knowledge_db.py --scan
```

作用：

- 创建基础表。
- 扫描 `data/docs`。
- 写入专题、来源文件、扁平知识点和专题知识点关联。

### 从 JSON 重建知识库

```bash
python backend/scripts/rebuild_knowledge_from_json.py --version 2026
```

常用参数：

```bash
python backend/scripts/rebuild_knowledge_from_json.py --version 2026 --subject math
python backend/scripts/rebuild_knowledge_from_json.py --version 2026 --input-files path/to/topic.json
python backend/scripts/rebuild_knowledge_from_json.py --version 2026 --clear-existing
```

作用：

- 从 `data/docs/{subject}/2026/*.json` 或指定 JSON 文件生成树状知识图谱。
- 写入 `topics`、`source_files`、`knowledge_points`、`topic_knowledge_points`、`knowledge_nodes`、`knowledge_edges`、`exam_insights`。
- 严重标题不匹配的 JSON 会跳过，避免污染知识库。

### 导入历史题库 JSON

```bash
python backend/scripts/import_question_banks.py
```

作用：

- 读取 `data/question_banks/*_question_bank.json`。
- 写入 `question_banks` 和 `questions`。
- 这是历史兼容脚本，新功能优先使用 `/api/banks/import-json` 或 `/api/banks/save`。

### 生成题目知识点关联

```bash
python backend/scripts/link_question_knowledge.py --reset
```

作用：

- 根据题干、解析、题库标题和专题关系做规则匹配。
- 写入 `question_knowledge_points`。
- 当前更适合作为候选生成，后续仍需要人工确认。

### 查询数据库

```bash
python backend/scripts/query_knowledge_db.py summary
python backend/scripts/query_knowledge_db.py topics --subject math --version 2026
python backend/scripts/query_knowledge_db.py knowledge-points --subject chinese
python backend/scripts/query_knowledge_db.py banks --subject math --limit 20
python backend/scripts/query_knowledge_db.py questions --subject math --limit 20
```
