# 数据库与题库接口说明

## 数据库位置

SQLite 数据库文件：

```text
data/knowledge/chunkao.db
```

当前数据库由 Python 标准库 `sqlite3` 创建和维护，暂未引入 Node.js SQLite 依赖。

## 数据表

| 表名 | 用途 |
| --- | --- |
| `subjects` | 学科基础表：语文、数学、英语 |
| `versions` | 版本表：2025、2026 |
| `topics` | 专题表，从 `data/docs` 扫描生成 |
| `knowledge_points` | 知识点表，当前由文件名和关键词推断生成 |
| `topic_knowledge_points` | 专题与知识点关联表 |
| `source_files` | 来源文件表，记录教师版/学生版 PDF 或 DOCX |
| `question_banks` | 题库表，从历史 JSON 题库导入 |
| `questions` | 题目表，保存题干、题型、答案、解析等 |

## 脚本

### 初始化知识点数据库

```bash
python backend/scripts/init_knowledge_db.py --scan
```

作用：
- 创建数据库和基础表。
- 扫描 `data/docs`。
- 入库专题、来源文件、知识点、专题-知识点关联。

当前结果：
- 专题：90 个
- 来源文件：180 个
- 知识点：121 个

### 导入历史 JSON 题库

```bash
python backend/scripts/import_question_banks.py
```

作用：
- 读取 `data/question_banks/*_question_bank.json`。
- 写入 `question_banks` 和 `questions`。
- 尝试按标题匹配已有 `topics`。

当前结果：
- 题库：14 个
- 题目：131 道
- 当前主要为语文题库

### 查询数据库

```bash
python backend/scripts/query_knowledge_db.py summary
python backend/scripts/query_knowledge_db.py topics --subject math --version 2026
python backend/scripts/query_knowledge_db.py knowledge-points --subject chinese
python backend/scripts/query_knowledge_db.py questions --subject chinese --limit 20
```

## 后端接口

基础路径：

```text
http://localhost:3001/api/knowledge
```

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| `POST` | `/init` | 初始化数据库并扫描 `data/docs` |
| `GET` | `/summary` | 查看数据库统计 |
| `GET` | `/topics?subject=math&version=2026` | 查询专题及关联知识点 |
| `GET` | `/points?subject=chinese` | 查询知识点 |
| `POST` | `/import-question-banks` | 导入历史 JSON 题库 |
| `GET` | `/questions?subject=chinese&limit=20` | 查询题目 |

## 当前限制

- 知识点仍是文件名和关键词推断，需做人工校对/合并。
- 题目表已存答案和解析，但未做分值、难度、知识点关联。
- Node 后端通过 Python 脚本访问 SQLite，性能足够用于当前本地项目；若后续接口调用频繁，可再引入 `better-sqlite3`。
