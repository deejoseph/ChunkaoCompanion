# 数据库与题库接口说明

## 数据库位置

SQLite 数据库文件：

```text
data/knowledge/chunkao.db
```

当前数据库由 Python 标准库 `sqlite3` 创建和维护，暂未引入 Node.js SQLite 依赖。

## 数据表

| 表名 | 用途 |
| --- | --- |
| `subjects` | 学科基础表：语文、数学、英语 |
| `versions` | 版本表：2025、2026 |
| `topics` | 专题表，从 `data/docs` 扫描生成 |
| `knowledge_points` | 知识点表，当前由文件名和关键词推断生成 |
| `topic_knowledge_points` | 专题与知识点关联表 |
| `source_files` | 来源文件表，记录教师版/学生版 PDF 或 DOCX |
| `question_banks` | 题库表，从历史 JSON 题库导入 |
| `questions` | 题目表，保存题干、题型、答案、解析等 |
| `question_knowledge_points` | 题目与知识点关联表，支持置信度和来源 |
| `question_assets` | 题目相关图片/公式/图形资产表，先保存资源路径，后续再做识别 |
| `question_parse_logs` | 题目解析和人工校对日志表 |

### 关键兼容字段

`questions.source_answer` 是当前 AI 参考答案和「修正答案」功能读取、更新的核心字段，不能删除、重命名或改语义。

本次数据库补强只做增量字段和新表：

- `question_banks.source_title/source_format/paper_type/year`
- `questions.page_number/source_file_id/parse_confidence/needs_review`
- `question_knowledge_points`
- `question_assets`
- `question_parse_logs`

这样后续可以继续补真题、分值、知识点、公式图形资产，同时不破坏现有 `source_answer` 修正链路。

## 脚本

### 初始化知识点数据库

```bash
python backend/scripts/init_knowledge_db.py --scan
```

作用：
- 创建数据库和基础表。
- 扫描 `data/docs`。
- 入库专题、来源文件、知识点、专题-知识点关联。

当前结果：
- 专题：90 个
- 来源文件：180 个
- 知识点：121 个

### 导入历史 JSON 题库

```bash
python backend/scripts/import_question_banks.py
```

作用：
- 读取 `data/question_banks/*_question_bank.json`。
- 写入 `question_banks` 和 `questions`。
- 尝试按标题匹配已有 `topics`。

当前结果：
- 题库：14 个
- 题目：131 道
- 当前主要为语文题库

### 题目关联知识点

```bash
python backend/scripts/link_question_knowledge.py --reset
```

作用：
- 根据题库匹配到的专题，继承专题知识点。
- 根据题干、解析、题库标题做关键词匹配。
- 写入 `question_knowledge_points`，保存 `confidence/source/note`。

当前结果：
- 已处理题目：131 道
- 已关联题目：131 道
- 题目-知识点关联：483 条

说明：
- 当前是基础规则关联，目的是先建立可校对底座。
- 后续真题入库时，AI 只建议低置信度题目的候选知识点，避免大量消耗额度。

### 导入历年真题 PDF

```bash
node backend/scripts/import_exam_papers.js
python backend/scripts/link_question_knowledge.py --reset
```

作用：
- 扫描 `data/exams/chinese`、`data/exams/math`、`data/exams/english`。
- 导入 2017-2025 年正式真题，暂时跳过 2026、`mock`、`listening`。
- 优先使用学生版/考试版切题，教师版或含答案版本作为参考文件记录。
- 写入 `question_banks` 和 `questions`，`paper_type='exam'`、`source='exam_pdf'`。
- 每道题写入一个 `question_assets` 记录，绑定原 PDF 路径和页码，用于公式、图形和版式校对。

当前真题入库结果：

| 学科 | 题库 | 题目 | 说明 |
| --- | ---: | ---: | --- |
| 语文 | 9 | 220 | 多数为试卷+答案合并 PDF，题块需校对 |
| 英语 | 9 | 349 | 2017-2024 较可用，2025 回忆版只有少量题块 |
| 数学 | 9 | 195 | 2017-2024 题数稳定，公式/图形需依赖 PDF 页码校对 |

当前真题知识点关联结果：

| 学科 | 真题题目 | 已关联题目 | 说明 |
| --- | ---: | ---: | --- |
| 语文 | 220 | 部分关联 | 阅读、文言文、作文等可规则匹配，细分仍需人工确认 |
| 英语 | 349 | 部分关联 | 已加入 Section 名称到知识点的规则映射 |
| 数学 | 195 | 大部分关联 | 函数、几何、代数、概率统计等可规则匹配 |

注意：
- 真题答案没有强行自动写入 `source_answer`，避免污染已可修正的标准答案字段。
- 数学 PDF 文本会丢失部分复杂公式、根号、分式和图形信息，所以 `question_assets` 的原 PDF 页码是后续校对的关键。
- 2026 资料回忆版较乱，暂不纳入自动导入。

### 查询数据库

```bash
python backend/scripts/query_knowledge_db.py summary
python backend/scripts/query_knowledge_db.py topics --subject math --version 2026
python backend/scripts/query_knowledge_db.py knowledge-points --subject chinese
python backend/scripts/query_knowledge_db.py banks --subject chinese --limit 20
python backend/scripts/query_knowledge_db.py questions --subject chinese --limit 20
```

## 后端接口

基础路径：

```text
http://localhost:3001/api/knowledge
```

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| `POST` | `/init` | 初始化数据库并扫描 `data/docs` |
| `GET` | `/summary` | 查看数据库统计 |
| `GET` | `/topics?subject=math&version=2026` | 查询专题及关联知识点 |
| `GET` | `/points?subject=chinese` | 查询知识点 |
| `GET` | `/banks?subject=chinese&limit=20` | 查询题库列表和知识点关联进度 |
| `POST` | `/import-question-banks` | 导入历史 JSON 题库 |
| `POST` | `/link-question-knowledge` | 用规则把题目关联到知识点，可传 `{ "subject": "chinese", "reset": true }` |
| `GET` | `/questions?subject=chinese&limit=20` | 查询题目 |
| `GET` | `/source-answers?subject=chinese&title=专题名` | 获取题库真实 `bankId` 和 `source_answer`，供 AI 参考答案修正使用 |

## 下一步入口

题库数据库下一阶段建议从这里继续：

1. 在 `backend/routes/docs.js` 的 `/parse` 或新增接口中增加 `saveToDb` 参数。
2. 将解析出的题目写入 `question_banks` 和 `questions`，保留 JSON 导出作为备份。
3. 对无法稳定识别的公式、图形、整页截图，先写入 `question_assets`。
4. 调用 `link_question_knowledge.py` 给新题生成基础知识点关联。
5. 在前端采集页增加“题目校对 + 知识点确认”界面，人工确认后更新 `question_knowledge_points`。
6. 对低置信度题目再调用 AI 生成候选知识点，不做全量 AI 分类。

## 当前限制

- 知识点仍是文件名和关键词推断，需做人工校对/合并。
- 题目表已存答案和解析；分值、难度字段已预留，但现有历史题库多为空。
- 题目-知识点关联目前是规则生成，需要人工校对提高质量。
- `question_assets` 表已预留，当前还没有自动截图/公式资产写入流程。
- Node 后端通过 Python 脚本访问 SQLite，性能足够用于当前本地项目；若后续接口调用频繁，可再引入 `better-sqlite3`。
