## 一、改造目标

实现题库模块的答案管理三层结构，支持：
1. **【参考答案】** - 试卷原始答案（不可修改的参考）
2. **【我的答案】** - 讨论后确定的最终答案
3. **【同学的答案】** - 多个AI模型的答案集合
4. **【讨论记录】** - 记录答案决策过程

## 三、技术细节

### 3.1 数据流

```
用户输入
  ↓
TextEditorWithShortcuts (支持快捷键)
  ↓
DataImport状态 (updateQuestion)
  ↓
导出JSON (exportToJson)
  ↓
后端保存 (POST /api/banks/save)
  ↓
数据库 + JSON文件
```

### 3.2 答案字段映射

| 前端字段 | 数据库字段 | JSON字段 | 类型 | 说明 |
|---------|---------|---------|------|------|
| sourceAnswer | source_answer | sourceAnswer | string | 试卷原答案 |
| finalAnswer | final_answer | finalAnswer | string | 最终答案（兼容） |
| myAnswer | my_answer | myAnswer | string | 我的答案 |
| peerAnswers | peer_answers | peerAnswers | JSON | 同学答案集 |
| aiAnswers | ai_answers | ai_answers | JSON | AI答案集 |
| discussion | discussion | discussion | string | 讨论记录 |

### 3.3 兼容性

✅ **向后兼容**：
- 旧数据的sourceAnswer、finalAnswer保留不变
- 新字段默认值为空，不影响现有数据
- JSON导出包含所有字段，缺失的用默认值

✅ **前向兼容**：
- 新前端可读取旧数据
- 旧前端无法访问新字段（但不会出错）

## 八、使用说明

### 编辑答案的完整流程

1. **打开题库编辑**
   - 点击"编辑"加载已有题库
   - 或点击"+ 添加题目"创建新题

2. **邀请AI讨论**（可选）
   - 点击"💬 邀请同学讨论"
   - AI会提供参考答案到【同学的答案】栏

3. **编辑答案**
   - 点击"✏️ 编辑答案"打开编辑器
   - 在三个区域编辑：参考答案、我的答案、讨论记录
   - 使用 Ctrl+Z/Y 撤销重做

4. **保存题库**
   - 确保所有题目的【我的答案】已填写
   - 点击"💾 保存到答案库"完成

### 快捷键速查

| 快捷键 | 功能 |
|--------|------|
| Ctrl+Z | 撤销 |
| Ctrl+Y | 重做 |
| Ctrl+Shift+Z | 重做（备选） |
| Ctrl+A | 全选 |

| Ctrl+V | 粘贴 |
| Ctrl+X | 剪切 |
