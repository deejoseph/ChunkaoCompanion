# 开发难点记录

## 一、答案库与知识点学习模块

### 1.1 生成知识点学习的答案库
**现状**：新资料采集模块可以导入题目并生成答案库，但答案库与知识点学习模块尚未打通。

**待实现**：
- 答案库依据原始答案生成，并在知识点学习区域提供「更正答案」功能键
- 用户发现答案错误时，可以一键修改答案库
- 修改后的答案同步更新到所有引用该题目的地方

**难点**：
- 答案库与知识点学习的关联关系设计
- 修改答案后的级联更新机制
- 用户修改记录与原始答案的区分存储

### 1.2 学生版测验答题卡生成
**现状**：学生版目前只是展示PDF，用户需要手写答题。

**待实现**：
- 根据答案库中的答案数据，生成标准化的答题卡（支持OCR识别）
- 答题卡格式需包含：题号、选项、填空区域、作文区域
- 支持多种题型（选择题、填空题、问答题）的自动排版

**难点**：
- 不同题型的答题卡布局算法
- 填空题区域的大小自适应
- 二维码/条形码标记题目ID，便于OCR识别对应

---

## 二、答题卡识别与评分系统

### 2.1 答题卡OCR识别
**待实现**：
- 拍照上传答题卡，自动识别手写答案
- 选择题：识别涂黑的选项（A/B/C/D）
- 填空题：OCR识别手写文字
- 问答题：识别手写内容并转文字

**难点**：
- 手写文字识别准确率（尤其是中英文混排）
- 拍照角度倾斜的自动校正
- 光照不均的图像预处理
- 涂卡识别的阈值算法

### 2.2 自动评分与成绩记录
**待实现**：
- 识别结果与答案库自动比对
- 选择题自动判分
- 填空题模糊匹配（同义词、近义词容错）
- 问答题关键词匹配评分
- 评分结果自动记录到成绩趋势图

**难点**：
- 填空题的语义相似度判断
- 问答题的评分标准设计
- 半自动评分（AI建议 + 人工确认）

---

## 三、知识库与智能出题系统

### 3.1 AI学习知识点
**待实现**：
- AI自动阅读专题内容，归纳总结知识点
- 构建结构化的知识库（知识点层级、关联关系）
- 根据知识库生成帮助学生复习的练习题

**难点**：
- 知识点自动抽取的准确性
- 知识图谱的构建与存储
- 基于知识点的题目生成算法

### 3.2 知识点标签体系
**待实现**：
- 依据学习进度中的知识点生成知识点类别
- 知识点类别映射到掌握雷达图的知识点维度
- 知识点类别映射到知识点热图的知识点标签

**难点**：
- 不同学科的知识点体系差异大
- 知识点粒度的确定（太细或太粗都不合适）
- 跨学科知识点的统一管理

---

## 四、真题分析与预测系统

### 4.1 历年真题知识点统计
**待实现**：
- AI解析2017-2026年真题试卷
- 提取每道题的知识点归属
- 统计各知识点每年分值分布
- 生成知识点热图（按学科、按年份）

**难点**：
- 知识点标注的一致性（同一知识点可能有不同表述）
- 复合知识点的拆分（一道题涉及多个知识点）
- 10年真题的批量处理效率

### 4.2 趋势分析与模拟试卷生成
**待实现**：
- 根据知识点热图的发展趋势，分析分值变化规律
- 预测未来考试可能的知识点分布
- 自动生成模拟试卷（含答案）

**难点**：
- 趋势预测算法的准确性
- 模拟试卷的难度控制
- 试卷结构的合理性（题型、分值分布）

## 五、口语练习进阶功能

### 5.1 场景化训练
**现状**：目前只有雅思Part1话题。

**待实现**：
- 针对不同短期目标的训练计划：
  - 签证面试场景
  - 求职面试场景
  - 商务会议场景
  - 旅游购物场景
  - 留学生活场景

**难点**：
- 不同场景的语料库建设
- 场景对话的流程设计
- 评分标准的多场景适配

### 5.2 发音纠正与跟读
**待实现**：
- Whisper本地部署，提升识别准确率
- 逐句跟读模式（Shadowing）
- 发音准确度评分（音素级别）
- 语调、重音、连读分析

**难点**：
- 音素级别的发音对齐算法
- 本地TTS的自然度
- 实时录音与波形显示的性能
