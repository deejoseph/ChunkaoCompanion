# 项目目录结构说明

本文档记录当前项目的目录职责和整理规则，用于后续开发时避免资料、运行代码、临时文件混在一起。

## 顶层目录

| 路径 | 用途 | 管理规则 |
| --- | --- | --- |
| `backend/` | Node.js + Express 后端服务 | 只保留运行代码、路由、服务、工具函数和必要脚本 |
| `frontend/` | React + Vite 前端应用 | 组件按功能拆分，复杂页面逐步拆到子目录 |
| `data/` | 本地学习资料和题库资源 | 大体量资料目录，不纳入 Git；不要随意移动现有结构 |
| `docs/` | 项目文档、安装指南、进度记录 | 开发进展统一写入 `docs/开发进度.md` |
| `backup/` | 本地归档区 | 不参与运行；用于保存旧脚本、资料包、临时测试文件 |

## 后端目录

| 路径 | 用途 |
| --- | --- |
| `backend/app.js` | 后端入口和路由注册 |
| `backend/routes/` | API 路由，按业务模块拆分 |
| `backend/services/` | AI、Whisper、字幕转换等服务逻辑 |
| `backend/scripts/` | 后端运行所需的 Python 辅助脚本 |
| `backend/utils/` | 通用工具函数 |
| `backend/uploads/` | 运行时上传文件，已加入忽略规则 |
| `backend/temp/` | 运行时临时文件，已加入忽略规则 |

## 前端目录

| 路径 | 用途 |
| --- | --- |
| `frontend/src/App.jsx` | 应用入口、导航和全局弹窗 |
| `frontend/src/components/` | 业务组件 |
| `frontend/src/components/Speaking/` | 口语练习相关组件 |
| `frontend/src/utils/` | 前端通用工具函数 |
| `frontend/public/` | 前端静态资源 |
