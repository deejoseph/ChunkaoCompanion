## 2026-05-22 任务 3：口语练习采集识别优化

### 已完成

- 快速模式恢复为浏览器 Web Speech API 实时识别，不再每次录音后调用 Whisper，降低日常练习等待时间。
- 精准模式保留 Whisper small 模型，用于正式评分和更准确转写。
- 新增后端常驻 Whisper worker：
  - `backend/services/whisper_worker.py`
  - `backend/services/whisperWorker.js`
- Whisper worker 通过 stdin/stdout 接收转录任务，模型加载后可跨请求复用，避免每次识别都重新启动 Python 并重新加载模型。
- `backend/routes/whisper.js` 改为调用常驻 worker，并新增 `/api/whisper/status` 用于查看 worker 状态。
- 前端口语练习新增识别状态提示、最近一次识别耗时显示。
- 识别结果支持提交前手动修正，避免识别误差直接影响 AI 评分。
- 评分模式新增 30/45/60/90 秒练习时长选择，并提示回答结构：直接回答、给原因、举例、简短收尾。
- 修复 `VoiceRecorder.jsx` 音量检测依赖 React 状态滞后的问题，改用 ref 追踪录音状态。

### 验证

- `npm.cmd run build` 成功。
- `node --check routes/whisper.js` 成功。
- `node --check services/whisperWorker.js` 成功。
- `python -m py_compile services/whisper_worker.py services/whisper_service.py` 成功。

### 已知限制

- Web Speech API 仍依赖浏览器支持，个别环境可能不可用。
- Whisper 首次精准识别仍需要加载模型，第一次会慢；后续请求应明显减少加载开销。
- 还没有做真实麦克风端到端人工验收，需要启动服务后在浏览器录音确认识别体验。
